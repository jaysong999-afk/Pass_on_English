**원어민 화상영어 플랫폼 서비스 앱 개발 요구사항 정리**

 

1\. 서비스명(상호): Pass on English

2\. 사업개요: 필리핀 영어 선생님들을 고용해 한국과 중국에서 학생들에게 Zoom으로 화상 수업 제공. 

\[수업료\]

|  | 한국 | 중국 |
| :---- | :---- | :---- |
| 주5회 20분(40회) | 87,000원 | 480위안 |
| 월수금 30분(12회) | 90,000원 | 490위안 |
| 화목(8회) | 64,000원 | 340위안 |

3\. 주요 개발 요구사항

1) 랜딩페이지  
* 전문 마케팅관점의 서비스 홍보 중심의 페이지   
2) 학생페이지  
* 학생으로 회원가입 및 로그인. 회원가입시 간단한 설문조사를 통해 영어 수준과 수강 목적(회화, 파닉스, 비즈니스 등) 등 정보 수집  
* 학생은 선생님 프로필을 확인하여 선생님을 선택할 수 있으며, 선생님 선택후 선생님 일정 가능한 시간대를 골라 수강신청 할 수 있음.  
* 최초 1회는 무료이며, 1회 수업 후 결재(계좌이체) 요청 메시지 보냄.  
* 수업료 결재 및 수강신청 완료   
* 학생은 본인의 수업스케줄표를 확인할 수 있으며, 1달에 2회 까지 개인 사정으로 인한 보강(수업일시 변경) 신청 가능(학생 변경요청 \-\> 선생님 알림 \-\> 선생님 승인 \-\> 변경완료)  
3) 선생님 페이지  
* 선생님으로 회원가입 및 로그인. 개인 프로필 등록  
* 본인이 수업 가능한 시간대 입력  
* 선생님은 본인 수업스케줄표를 확인할 수 있으며, 개인사정 발생시 보강(수업일시 변경) 신청 가능(선생님 변경요청 \-\> 학생 알림 \-\> 학생 승인 \-\> 변경완료)  
* 매 수업완료 후 스케줄표에서 클릭하여 수업완료 및 수업 피드백 작성  
* 월별 예상 급여가 실시간으로 표시됨  
4) 관리자 페이지  
* 학생현황확인(현재 수강중 학생들의 정보 리스트, 입금여부 확인버튼으로 수업승인, 과거 수강자도 조회 가능)  
* 선생님 현황확인(선생님 정보, 현재 수업 정보, 급여 정보 설정 및 조회 가능, 보너스 별도 입력 가능)  

                         선생님 급여 \= 수업시간(시간) \* 설정급여+1달 결근(수업 변경 포함)없이 만근시 보너스 (25페소/시간,수정가능)+3달 만근시 보너스(3개월 총 300시간 이상 수업시 2,000페소, 150\~299시간 1,300페소, 150시간 이하 700페소)+(기타 보너스)                         

* 재무현황(수입, 지출 관리, 선생님 급여 정산, 월,분기,년 결산(차트 등 시각화)  
* **메시지 · CS 센터** (`/admin/messages`): 학생·선생님 채팅 모니터링, 관리자 1:1 CS, 단체 발송, Web Push 발송 내역 (UI·API 연동 완료 — 상세 §6)
5) 기타  
* 현재버전은 결재 시스템은 별도 구축 안하고 계좌이체로만 수강료 징수함.  
* 채팅기능이 포함되어 수강신청 완료 후 선생님과 학생간 채팅 가능. 또는 관리자의 메시지 발송 가능(인스타그램 DM과 유사하게)  
* 디자인은 아이들과 학부모들도 친숙하고 서비스와도 잘 어울리도록 AI가 세련되게 설계할것  
* 언어는 가변적으로 선택가능하며, 한국, 중국, 필리핀(영어) 각 국가에서 접속되는 언어가 우선적으로 선택되어야함.  
- 랜딩페이지(한국어, 중국어, 영어)  
- 학생페이지(한국어, 중국어)  
- 선생님페이지(영어)  
- 관리자페이지(한국어)  
* 배포시 도메인은 반드시 중국과 한국 양 국가에서 접속가능해야함.(Tencent Cloud 홍콩 리전 사용)  
* 중국에서 사용 불가한 기술 스택을 사용해서는 안됨  
* 앱개발없이 PWA (Progressive Web App) \+ Web Push 방식으로 "홈 화면에 추가" 를 유도하여 채팅 및 알림기능을 구현 함.  
* 화상수업프로그램(Zoom 등)은 연동하지 않음.

## 6. 관리자 메시지 · CS 센터 (UI·API 연동, 2026-08)

**경로**: `/admin/messages`  
**구현**: `AdminMessagesHub` (`src/components/admin/messages/`)

> **2026-08 업데이트**: 관리자 메시지·CS·브로드캐스트·Push·인앱 알림 백엔드 **연동 완료**. 예약 발송 cron + VAPID Web Push + CTR 클릭 추적 포함. **자동 시스템 알림 발송 엔진만** 배포 후 (규칙 ON/OFF 저장은 DB 반영됨).

### 6.1 탭 구성

| 탭 | 컴포넌트 | 목적 | 프론트 상태 | 백엔드 |
|----|----------|------|-------------|--------|
| CS · 1:1 | `CsManagerPanel` | 채팅 모니터링 + 관리자 직접 1:1 | ✅ | ✅ API 연동 |
| 단체 발송 | `BroadcastPanel` | 세그먼트·조건 브로드캐스트 | ✅ | ✅ API + cron |
| Push · 알림 | `PushNotificationsPanel` | Push 발송 내역·통계 | ✅ | ✅ API (규칙 저장만; **자동 발송 제외**) |

### 6.2 CS · 1:1 (`CsManagerPanel`)

#### (1) 채팅 모니터링
- 학생↔선생님 **채팅방 목록** 조회 (기존 `GET /api/chat/rooms?role=admin`)
- 방 선택 시 **열람 전용** 대화 (`ChatMonitorThread` — `GET /api/chat/messages`)
- **관리자 참여** → 기존 `/admin/chat/[roomId]` + `ChatThread` 이동
- 검색: 표시명·마지막 메시지

#### (2) 관리자 1:1 직접 메시지
- 학생(학부모)·선생님과 **관리자 전용 1:1** 대화 UI (3단 레이아웃: 목록 · 대화 · 템플릿)
- **새 1:1 대화**: 대상 선택 (`GET /api/admin/students`, `GET /api/admin/teachers`)
- 메시지 전송·스레드 목록: **`/api/admin/messages/direct`** 연동
- Quick Replies: **`GET /api/admin/messages/quick-replies`**

#### (3) 자주 쓰는 답변 (Quick Replies)
- 카테고리: 결제 / 수업 / 기술 / 규정
- 템플릿 예: 계좌이체 안내, 보강 규정, Zoom 접속, 수업 리마인더, 입금 확인 완료
- 1클릭 → 관리자 1:1 입력창에 삽입 (API 템플릿)

### 6.3 단체 · 전체 발송 (`BroadcastPanel`)

| 항목 | UI 옵션 |
|------|---------|
| 대상 | 전체 / 학생 전체 / 학생·한국 / 학생·중국 / 선생님 전체 |
| 조건 필터 (학생) | 수강 중, 만료 임박, 결제 대기, 신규 가입 대기, 수강 완료 |
| 발송 채널 | 푸시+채팅 / 푸시만 / 채팅만 |
| 예약 | `datetime-local` → **`/api/cron/process-scheduled-broadcasts`** |
| 예상 대상 수 | **`GET /api/admin/messages/broadcast/preview`** |

### 6.4 Push · 알림 (`PushNotificationsPanel`)

| 영역 | 프론트 | 백엔드 |
|------|--------|--------|
| KPI 카드 | 총 발송, 전달 성공률, 실패, CTR | ✅ **`GET /api/admin/messages/campaigns`** |
| 발송 내역 테이블 | DB 캠페인 목록 | ✅ API 연동 |
| **자동 시스템 알림** | 규칙 목록·토글·저장 UI (**향후 구축 예정** 배지) | 규칙 **저장만** (`PATCH notification-rules`) · **발송 엔진 제외** |

#### 자동 시스템 알림 (배포 후 구현 예정)
- 수업 10분 전 리마인더
- 입금 확인 완료 알림
- 보강/일정 변경 요청·승인 알림
- 미확인 채팅 일일 요약 (선택)
- 수강 만료 7일 전 안내

### 6.6 백엔드 연동 우선순위 (제안)

1. **단체 발송** — 세그먼트 집계 + Push/채팅 발송 API  
2. **관리자 1:1** — admin↔user 전용 채팅방·메시지 API  
3. **Push 발송 내역** — 캠페인·전달·클릭 집계  
4. **자동 시스템 알림** — 규칙 엔진 + cron/Edge Function (배포 후)
